The problem

One request to an agent becomes dozens of calls. Nobody governs the whole task.

API gateways check one request at a time. LLM gateways meter per key or per month. Limits inside agent code stop at the agent's own process. A task stuck in a loop can spend a team's monthly budget, and afterwards nobody can say which agent did what.

How it works

Govern the task, not the request.

Every call in a task carries one run ID. agentgw sits in the network path, so it sees each model call, tool call and hand-off to another agent, and charges them all to the same run.

  1. Identity

    Agents sign in with Kubernetes service-account tokens, Cognito tokens or keys. The person's token is verified too, and each run belongs to one person.

  2. Policy

    Each agent gets default-deny lists of the models, tools, services and agents it may use. Policy is reviewed config in Git.

  3. Budget

    Steps, tool calls, tokens, dollars, time and delegation depth are capped per task, across every agent in it.

  4. Record

    One ledger line per call: run, agent, person, target, tokens, cost and outcome.

What it enforces

Built and tested today.

built

Run budgets

Hard caps per task on steps, tool calls, tokens, dollars, wall time and delegation depth.

built

Loop detection

Stops repeated calls, two agents cycling, and streaks of failures. Halt or warn.

new

Tool pinning

Fingerprints every MCP tool definition. A tool whose description changes is hidden and blocked until someone approves it.

built

Human approval

Risky tools wait for a single-use approval. Retries never send the same email twice.

built

Agent and user identity

Service-account tokens instead of client secrets. The person behind each task is verified and recorded.

built

Long sessions survive

When a prompt outgrows the model, older turns are summarized by a smaller model and the task continues.

built

GPU-aware routing

Each task sticks to one model pod to reuse its cache. Failing pods are skipped; a fallback model takes over.

built

Document AI governed

OCR, parsing, table detection, embeddings and reranking count toward the same task budget.

built

Kubernetes native

Signed Helm chart, hardened pod, readiness tied to the identity provider, Prometheus metrics.
